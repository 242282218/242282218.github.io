# 使用说明

## 本地运行

需要 Node.js 22.12+ 和 pnpm 10。在项目根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

发布前运行 `pnpm test && pnpm check && pnpm build`。

## 新增文章

在 `src/content/blog/` 添加 Markdown 文件，例如 `hello-world.md`：

```md
---
title: 第一次记录
description: 这篇文章会记录什么，写成一句话。
pubDate: 2026-09-26
tags: [学习笔记]
draft: true
---

从这里开始写正文。
```

写完并确认可以公开后，将 `draft` 改为 `false`。文件名决定文章地址，例如 `hello-world.md` 对应 `/blog/hello-world/`。文章按发布日期倒序排列；草稿不会生成公开页面，也不会进入 RSS。

文章配图放在 `public/images/`，正文中使用普通 Markdown 图片语法，通过 `/images/文件名.webp` 引用。不要提交密钥或私人笔记。

## 修改个人资料

首页、关于和项目的文案分别位于 `src/pages/index.astro`、`src/pages/about.astro`、`src/pages/projects.astro`；站点标题和导航位于 `src/layouts/BaseLayout.astro`。准备好真实资料后再替换现有空状态。
